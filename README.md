# Safar Kitobi

**Har bir joy — bir sahifa.** O'zbekiston bo'ylab sayohat kitobi: turist joydagi QR kodni skanerlaydi, sahifa (muhr) oladi va darajalar bo'yicha sovg'alar yutadi. Birinchi tuman: **Kitob** (Qashqadaryo).

## Ishga tushirish

```bash
npm install
npm run dev          # http://localhost:5173
npm run build        # dist/ papkasi — hostingga shu yuklanadi
npm run qr           # QR kodlar va taxtachalar (chop-etish/qr/)
```
